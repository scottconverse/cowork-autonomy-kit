A DEVELOPMENT ENVIRONMENT, AS CODE

Less setup archaeology.
More visible state.

The kit brings together the pieces that otherwise live in scattered shell commands and personal instructions. It is a functional, evolving toolkit for developers who are comfortable reviewing scripts and managing their own machine.

01 / PREPARE

Build the toolchain

Setup checks for Python, uv, Scoop, Node, GitHub CLI, ripgrep, jq, SQLite, and Playwright. It installs missing components, preferring user-scope channels.

02 / CONFIGURE

Keep a standing brief

A compact Core profile handles everyday work; a deeper software-development profile covers broader tasks. Setup stages updates and preserves existing live instruction files for manual merging.

03 / ELEVATE

Separate admin work

A scheduled-task helper handles package installs, services, private-profile firewall rules, and PowerShell scripts from designated development roots. Job results and logs stay on your machine.

04 / INSPECT

Know what changed

Doctor reports toolchain and configuration state. Regression scripts check settings merges, JSON paths, and installer results. Uninstall reverses the configuration layer while leaving general-purpose tools in place.

START WITH A REVIEW

Your machine.
Your decision.

Download the release, inspect the scripts, and read the setup guide before running anything. This is an environment-changing kit, not a browser-only extension.

  1. Review the release

    Use the ZIP and SHA-256 checksum in the v1.5.2 release. Windows, PowerShell, internet access, and an existing Claude installation are needed. The kit does not install Claude itself.

  2. Run setup deliberately

    Extract the ZIP and run Install.cmd from the kit folder. The optional elevated helper requests Windows UAC approval. Restart Cowork afterward so environment changes load.

  3. Inspect and maintain

    Run Doctor-Autonomy.ps1 to inspect state. Existing helper installations must run the helper installer directly to update; merge revised Core guidance into your live instructions separately.

IMPORTANT BEFORE INSTALLING

Understand the permission changes.

Setup sets Claude Code's bypassPermissions mode and installs an approval watcher that clicks desktop permission dialogs automatically. This reduces opportunities to review individual actions.

The elevated helper can run administrator-level scripts. Its trusted-path check is not a sandbox for what those scripts can do.

WHAT IS VERIFIED

Useful today.
Still evolving.

v1.5.2 fixes the Playwright step in Setup, which stopped on clean machines before it installed Playwright. The fix was parse-checked and logic-tested outside Windows; it was not run on Windows PowerShell 5.1 for this release.

v1.5.1 fixed installation of the JSON-safe job invoker and requires administrator and Windows-path self-tests to pass before reporting success. For v1.5.1, helper regressions passed 14 checks; the machine capability harness reported 13 passes, 0 failures, 2 informational results on the maintainer's existing Windows installation. These are test results, not compatibility guarantees.

Clean-machine lifecycle testing and native Cowork behavior testing were not performed for this release. The approval watcher's behavior was not independently tested during the helper fix.
