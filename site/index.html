A DEVELOPMENT ENVIRONMENT, AS CODE

Less setup archaeology.
More visible state.

The kit brings together the pieces that otherwise live in scattered shell commands and personal instructions. It is a functional, evolving toolkit for developers who are comfortable reviewing scripts and managing their own machine.

01 / PREPARE

Build the toolchain

Setup checks for Python, uv, Scoop, Node, GitHub CLI, ripgrep, jq, SQLite, and Playwright. It installs missing components, preferring user-scope channels.

02 / CONFIGURE

Keep a standing brief

A compact Core profile handles everyday work; a deeper software-development profile covers broader tasks. Setup stages updates and preserves existing live instruction files for manual merging.

03 / ELEVATE

Separate admin work

A scheduled-task helper handles package installs, services, private-profile firewall rules, and PowerShell scripts from designated development roots. Job results and logs stay on your machine.

04 / INSPECT

Know what changed

Doctor reports toolchain and configuration state. Regression scripts check settings merges, JSON paths, and installer results. Uninstall reverses the configuration layer while leaving general-purpose tools in place.

START WITH A REVIEW

Your machine.
Your decision.

Download the release, inspect the scripts, and read the setup guide before running anything. This is an environment-changing kit, not a browser-only extension.

  1. Review the release

    Use the ZIP and SHA-256 checksum in the v1.6.1 release. Windows, PowerShell, internet access, and an existing Claude installation are needed. The kit does not install Claude itself.

  2. Run setup deliberately

    Extract the ZIP and run Install.cmd from the kit folder. In Claude: Settings, Claude Code, turn on 'Allow bypass permissions mode'. Without it the Code tab cannot use Bypass permissions. The optional elevated helper requests Windows UAC approval. Fully quit Claude (right-click the Claude icon in the system tray, Quit), then open it again. A new session alone does not load new PATH entries; the desktop app does not read PowerShell profiles.

  3. Inspect and maintain

    Run Doctor-Autonomy.ps1 to inspect state. Setup repairs stale helper installations and updates unchanged kit profiles during Setup. Customized instructions remain intact; merge new guidance into them manually.

IMPORTANT BEFORE INSTALLING

Understand the permission changes.

Setup sets bypassPermissions unless -SkipBypass is passed, merges settings and a PowerShell notification hook, and asks for confirmation unless -Yes is passed. No watcher automatically clicks permission dialogs.

The elevated helper can run administrator-level scripts. Its trusted-path check is not a sandbox for what those scripts can do.

WHAT IS VERIFIED

Useful today.
Still evolving.

v1.6.1 targets the Claude Code desktop Code tab and CLI, protects helper program files, removes the approval watcher, and adds tests of the real configuration and rollback functions.

Windows PowerShell 5.1 regression and isolated lifecycle tests are included. Clean-machine installation was not performed. Verification passed a fresh desktop Code session and elevated helper on an existing Windows installation. This patch release includes the Claude-specific audit fixes.

Bypass mode provides no protection against prompt injection. With the helper installed, trusted scripts can execute as administrator without a per-action UAC prompt. The owner accepts this risk; deny rules remain available.
